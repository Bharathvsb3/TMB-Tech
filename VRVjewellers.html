V.R.V ஜுவல்லர்ஸ் – கடை மென்பொருள் பயனர் வழிகாட்டி
V.R.V Jewellers – Shop Software · User Flow Guide

Version 1.1 · 13-Oct-2026 · Android (Mobile / Tab) · Windows · Website · தமிழ் & English

இந்த வழிகாட்டி கடை உரிமையாளர், மேலாளர் மற்றும் பணியாளர்களுக்காக. ஒவ்வொரு திரையும் படத்துடன், படிப்படியாக விளக்கப்பட்டுள்ளது. மேலே உள்ள பொத்தானில் மொழியை மாற்றலாம்.This guide is for the shop Owner, Manager and Workers. Every screen is explained step by step with a picture. Use the button at the top to switch language.

1இந்த மென்பொருள் என்ன? / What is this software?

ஒரே மென்பொருள் – மூன்று இடங்களில் ஒரே மாதிரி வேலை செய்யும். ஒரு இடத்தில் போட்ட மதிப்பீடு (Estimation), அடகு, சீட்டு எல்லாம் மற்ற இடங்களிலும் உடனே தெரியும்.One software that works the same way in three places. An estimation, loan or chit entered on one device is visible on all the others immediately.

📱 Android Mobile / Tab

கடையில் கவுண்டரில் டேப், உரிமையாளர் கையில் மொபைல். கேமரா மூலம் கையெழுத்து படம், புஷ் அறிவிப்பு, அழைப்பு (Call) வசதி.Tab at the counter, mobile in the owner's hand. Camera for signature photos, push notifications and calls.

🖥️ Windows

கணினியில் பெரிய திரை – பில்/மதிப்பீடு வேகமாக போட, ரிப்போர்ட் பார்க்க, பிரிண்டர் இணைக்க.Big screen on the PC: fast estimations, reports and printers.

🌐 Website

எந்த பிரவுசரிலும் லாகின் செய்து அதே திரைகள். தனியாக பொது இணையதளத்தில் நகை கேட்டலாக் (Catalogue) தெரியும்.Log in from any browser and get the same screens. The jewellery catalogue also appears on the public website.

யார் யார் பயன்படுத்துவார்கள்? / Who uses it?

OWNER உரிமையாளர்

கடையின் எல்லா மெனுவும் எப்போதும் உண்டு. பயனர்களை சேர்க்கலாம், அனுமதி கொடுக்கலாம், எந்த பதிவையும் திருத்தலாம். யாருக்கு எந்த அறிவிப்பு போக வேண்டும் என்றும் உரிமையாளரே முடிவு செய்வார்.Always has every shop menu. Adds users, gives permissions and can edit any record. The owner also decides which notifications go to whom.

MANAGER மேலாளர்

உரிமையாளர் கொடுத்த மெனு மட்டும். அனுமதி இருந்தால் பணியாளர்களை சேர்த்து, தன்னிடம் உள்ள அனுமதிக்குள் மட்டும் அவர்களுக்கு கொடுக்கலாம்.Sees only the menus the owner gives. With permission, a manager can add workers and pass on only the permissions the manager already has.

WORKER பணியாளர்

கொடுத்த வேலை மட்டும் – உதா: “தங்க மதிப்பீடு – சேர்க்க மட்டும்”. சேமித்த பின் திருத்த முடியாது (அனுமதி இல்லையென்றால்).Only the assigned work, for example “Gold estimation – Add only”. Without Edit permission, a worker cannot change a record after saving it.

SUPER ADMIN சூப்பர் அட்மின்

மென்பொருள் தயாரிக்கும் நிறுவனம் (TMB Tech) மட்டும் – உரிமையாளருக்கும் மேலே உள்ள பங்கு. கடை பயனர்களுக்கு இந்த கணக்கும் இதன் பக்கங்களும் தெரியாது. பிழைகள், லாகின் பதிவு, Backup, மென்பொருள் நலம் பார்த்து பிரச்சனையை சரிசெய்ய. உரிமையாளரால் இதை பார்க்கவோ நீக்கவோ முடியாது (பகுதி 23).Only for the software company (TMB Tech), a role above the owner. Shop users never see this account or its pages. It is used to check errors, login history, backups and system health, and to fix problems. The owner cannot see or remove it (section 23).

✔ கணினி அனுபவம் இல்லாதவர்களுக்கும் எளிது: பெரிய பொத்தான்கள், தமிழ் எழுத்து, ஒரு திரையில் ஒரே வேலை, ஒவ்வொரு செயலுக்கும் பச்சை “வெற்றி” செய்தி, தவறு இருந்தால் சிவப்பில் எங்கே தவறு என்று காட்டும்.✔ Easy even for people new to computers: big buttons, Tamil text, one job per screen, a green “success” message after every action, and errors shown in red right where the mistake is.

2தோற்றம், தீம்கள் & அனிமேஷன் / Look, themes & animation

இயல்பு தீம் “மெரூன் கிளாசிக்” – கடை பேனரில் உள்ள அதே நிறங்கள்: அடர் சிவப்பு (மெரூன்), தங்கம், கிரீம். பார்த்தவுடனே “V.R.V” என்று தெரியும். லைட் கோல்ட் தீமும் உண்டு – கீழே பார்க்கவும்.The default theme, “Maroon Classic”, uses the shop banner's colours (deep maroon, gold and cream), so the app is recognisably “V.R.V” at a glance. இரண்டு தீம்கள் / Two themes

இரண்டு தீம்கள்: மெரூன் கிளாசிக் (இயல்பு) மற்றும் லைட் கோல்ட். லைட் கோல்டில் மேல் பட்டை, மெனு, பொத்தான்கள் எல்லாம் மெதுவாக மினுங்கும் வெளிர் தங்க நிறம் – அடர் இல்லை, நகை போல் பளபளப்பு. கீழே உள்ள அட்டையை தொட்டால் இந்த முழு ஆவணமும் அந்த தீமுக்கு மாறும்; மேலே உள்ள 🎨 வட்டங்களிலும் மாற்றலாம்.Two themes: Maroon Classic (default) and Light Gold. In Light Gold the top bar, menu and buttons are a soft metallic light gold with a slow shimmer, never dark, like polished jewellery. தீம் விதிகள் / Theme rules

  • லாகின் பக்கம் எப்போதும் கடையின் இயல்பு தீமில் வரும்.The login page always uses the shop's default theme.
  • லாகின், முகப்பு (Dashboard) இரண்டிலும் உங்கள் பேனரில் உள்ள முருகன் படம் – தங்க வளைவு சட்டத்தில், மெதுவான ஒளிவட்டத்துடன்.Login and the home dashboard both show the Murugan image from your banner in a gold temple-arch frame with a gentle glowing halo.
  • பிரிண்ட் (மதிப்பீடு, அடகு, லேபிள்) தீமால் மாறாது – எப்போதும் கடையின் பிரிண்ட் நிறம்.Prints (estimation, loan, label) never change with the theme; they always use the shop's print colours.
  • பச்சை = வெற்றி, சிவப்பு = எச்சரிக்கை – இரண்டு தீமிலும் ஒரே அர்த்தம்.Green means success and red means warning in both themes.
